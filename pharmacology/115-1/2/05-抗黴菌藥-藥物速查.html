Antifungal agents · Drug reference

MechanismsBlock 2

Imidazoles

Ketoconazole; clotrimazole; miconazole

→ Ergosterol synthesis ↓

Main uses · 主要用途

Superficial fungal infection; clotrimazole / miconazole commonly topical.

Adverse effects / interactions · 副作用

Local irritation with topical products; systemic ketoconazole: hepatotoxicity, endocrine effects, CYP interactions.

Distinguish · 辨別重點

不要把外用藥膏的風險與口服 ketoconazole 混成一組。

Triazoles: fluconazole

Fluconazole

→ 14α-demethylase inhibition

Main uses · 主要用途

Susceptible Candida; cryptococcal consolidation / maintenance (regimen dependent).

Adverse effects / interactions · 副作用

Liver injury; QT prolongation; CYP interactions. Renal elimination → renal-dose adjustment.

Distinguish · 辨別重點

Good CSF penetration; no reliable Aspergillus coverage.

Triazoles: itraconazole

Itraconazole

→ 14α-demethylase inhibition

Main uses · 主要用途

Dermatophytes and selected endemic / dimorphic mycoses.

Adverse effects / interactions · 副作用

Heart failure / negative inotropy; liver injury; CYP interactions; GI intolerance.

Distinguish · 辨別重點

Absorption depends on formulation; not interchangeable with fluconazole.

Mold-active triazoles

Voriconazole; posaconazole; isavuconazole

→ 14α-demethylase inhibition

Main uses · 主要用途

Selected invasive mold infections. Voriconazole: Aspergillus; posaconazole / isavuconazole also have Mucorales activity.

Adverse effects / interactions · 副作用

Liver injury and drug interactions; voriconazole: visual / neuropsychiatric effects, photosensitivity / skin malignancy risk.

Distinguish · 辨別重點

Spectrum differs by drug. Isavuconazole SHORTENS QT; do not memorize all azoles as QT prolongers.

Systemic polyenes

Amphotericin B; lipid / liposomal formulations

→ Existing ergosterol binding → permeability ↑

Main uses · 主要用途

Severe systemic mycoses; cryptococcal induction in combination with flucytosine; broad yeast / mold / dimorphic activity.

Adverse effects / interactions · 副作用

Infusion fever / chills; nephrotoxicity; K⁺ / Mg²⁺ loss; anemia. Lipid formulations generally reduce nephrotoxicity.

Distinguish · 辨別重點

主要毒性是腎與輸注反應；不要背成「絕不會有肝異常」。Poor CSF concentration does not mean no role in cryptococcal meningitis.

Local polyenes

Nystatin (textbook supplement)

→ Ergosterol binding

Main uses · 主要用途

Mucocutaneous Candida; local / oral nonabsorbed therapy.

Adverse effects / interactions · 副作用

Local irritation; GI upset.

Distinguish · 辨別重點

Not a systemic treatment; not a dermatophyte drug.

Allylamines

Terbinafine

→ Squalene epoxidase inhibition

Main uses · 主要用途

Dermatophyte infection; oral treatment of onychomycosis; topical preparations for superficial disease.

Adverse effects / interactions · 副作用

Rare severe hepatotoxicity; taste / smell disturbance; rash. Oral therapy: avoid active / chronic liver disease; CYP2D6 inhibition.

Distinguish · 辨別重點

Keratin affinity; check liver status for oral treatment. Human CYP2D6 ≠ fungal squalene epoxidase.

Echinocandins

Caspofungin; micafungin; anidulafungin

→ β-1,3-D-glucan synthase inhibition

Main uses · 主要用途

Invasive Candida; selected Aspergillus salvage / adjunct contexts.

Adverse effects / interactions · 副作用

Generally well tolerated; infusion / histamine reactions; liver-enzyme abnormalities can occur.

Distinguish · 辨別重點

IV; poor CSF / urinary exposure. Not reliable for Cryptococcus or Mucorales; not universal first-line monotherapy for Aspergillus.

Pyrimidine antimetabolites

Flucytosine

→ Fungal conversion to 5-FU → DNA / RNA effects

Main uses · 主要用途

Cryptococcal meningitis, usually combination therapy with amphotericin B.

Adverse effects / interactions · 副作用

Bone-marrow suppression; liver abnormalities; GI effects. Renal accumulation increases toxicity.

Distinguish · 辨別重點

Good CSF penetration; renal elimination. Rapid resistance → avoid routine monotherapy.

Mitotic inhibitors

Griseofulvin

→ Tubulin binding → mitotic spindle disruption

Main uses · 主要用途

Dermatophytes; especially Microsporum tinea capitis (lecture emphasis).

Adverse effects / interactions · 副作用

Headache / CNS effects; GI upset; hepatotoxicity; photosensitivity; CYP induction and interactions.

Distinguish · 辨別重點

Deposits in keratin; fatty meal improves absorption. Not for Candida; porphyria contraindication.
