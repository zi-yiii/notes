Immunopharmacology agents · Drug reference

MechanismsBlock 2

Global gene regulation

Prednisone / prednisolone; dexamethasone

→ GR-mediated gene regulation

Main uses · 用途

Autoimmune disease; transplant-related immunosuppression.

Adverse effects / interactions · 副作用

Infections, hyperglycemia, osteoporosis, adrenal suppression; effects depend on dose / duration.

Distinguish · 易混點

Cross-reference the adrenal corticosteroid unit; steroid neutrophilia ≠ enhanced immune function.

IMPDH inhibitors

Mycophenolate mofetil → mycophenolic acid

→ De novo guanosine synthesis ↓

Main uses · 用途

Transplant rejection prevention; lupus nephritis; selected refractory GVHD contexts.

Adverse effects / interactions · 副作用

GI effects, reversible marrow suppression; serious infection; embryofetal toxicity.

Distinguish · 易混點

Purine / guanosine supply; compare DHODH inhibition.

DHODH inhibitors

Leflunomide → teriflunomide

→ Pyrimidine synthesis ↓

Main uses · 用途

Leflunomide: RA; teriflunomide: relapsing MS (drug-specific use).

Adverse effects / interactions · 副作用

Hepatotoxicity, diarrhea, alopecia; embryofetal toxicity; prolonged elimination.

Distinguish · 易混點

Do not equate leflunomide and teriflunomide approved indications; long persistence matters.

Calcineurin inhibitors

Cyclosporine; tacrolimus

→ Calcineurin → NFAT → IL-2 production ↓

Main uses · 用途

Transplant immunosuppression; selected autoimmune / topical uses.

Adverse effects / interactions · 副作用

Nephrotoxicity, neurotoxicity, hyperkalemia; CYP3A interactions. Tacrolimus: hyperglycemia; cyclosporine: gingival hyperplasia / hirsutism.

Distinguish · 易混點

Cyclosporine binds CYCLOPHILIN; tacrolimus binds FKBP12.

mTOR inhibitors

Sirolimus; everolimus; temsirolimus

→ FKBP12 complex → mTORC1 inhibition

Main uses · 用途

Sirolimus / everolimus: selected transplant uses; rapalog oncology indications differ by drug.

Adverse effects / interactions · 副作用

Marrow suppression, thrombocytopenia, hyperlipidemia, impaired wound healing, pneumonitis.

Distinguish · 易混點

Same FKBP family as tacrolimus, different target. Do not memorize as absolutely no renal effects.

TNF neutralizers

Etanercept; infliximab; adalimumab; golimumab; certolizumab pegol

→ TNF neutralization

Main uses · 用途

RA / psoriatic arthritis / spondyloarthritis; indications differ among drugs.

Adverse effects / interactions · 副作用

Serious infection, latent TB reactivation, demyelination; heart failure concerns.

Distinguish · 易混點

Etanercept is receptor–Fc, not an antibody; certolizumab is PEGylated Fab. Do not transfer all IBD indications to etanercept.

Immunomodulatory agents

Thalidomide

→ Multiple immune / angiogenesis effects; TNF modulation

Main uses · 用途

Multiple myeloma (lecture focus).

Adverse effects / interactions · 副作用

Severe teratogenicity, peripheral neuropathy, constipation; thromboembolism.

Distinguish · 易混點

Not simply a monoclonal anti-TNF antibody.

IL-1 pathway blockers

Anakinra; canakinumab; rilonacept

→ Receptor antagonist / ligand antibody / ligand trap

Main uses · 用途

RA (anakinra); selected autoinflammatory syndromes including CAPS (drug-specific).

Adverse effects / interactions · 副作用

Infections, injection reactions; neutropenia can occur.

Distinguish · 易混點

Anakinra targets receptor signaling; canakinumab targets IL-1β; rilonacept is a trap.

IL-6R blockers

Tocilizumab

→ Membrane and soluble IL-6 receptor blockade

Main uses · 用途

RA / JIA / giant-cell arteritis; selected CRS and SSc-ILD uses per lecture.

Adverse effects / interactions · 副作用

Infection, liver injury, neutropenia; GI perforation concern.

Distinguish · 易混點

Blocks receptor, not direct neutralization of IL-6 ligand.

IL-17A neutralizers

Secukinumab

→ IL-17A ligand neutralization

Main uses · 用途

Psoriasis, psoriatic arthritis, axial spondyloarthritis.

Adverse effects / interactions · 副作用

Infections, mucocutaneous Candida; inflammatory bowel disease concern.

Distinguish · 易混點

Lecture also mentions chronic graft fibrosis; do not present that as a routine established indication.

CD25 blockers

Basiliximab; daclizumab (historical)

→ IL-2Rα blockade

Main uses · 用途

Transplant rejection prophylaxis (basiliximab).

Adverse effects / interactions · 副作用

Hypersensitivity; infection risk in combination immunosuppression.

Distinguish · 易混點

Blocking activated T-cell proliferation is not the same as broad T-cell depletion. Daclizumab is historical.

Cell-depleting antibodies

Rituximab / ofatumumab (CD20); alemtuzumab (CD52)

→ Antibody effector mechanisms deplete target-positive cells

Main uses · 用途

CD20: B-cell malignancies / selected autoimmune uses; alemtuzumab uses depend on formulation and disease.

Adverse effects / interactions · 副作用

Infusion reactions, serious infection; CD20: HBV reactivation / rare PML; CD52: prolonged lymphopenia / autoimmune complications.

Distinguish · 易混點

CD20 is B-cell-focused; CD52 is broadly expressed. Not every plasma cell expresses CD20.

Historical anti-CD3

Muromonab-CD3 (OKT3)

→ T-cell function modulation / depletion

Main uses · 用途

Historical transplant rejection therapy in lecture.

Adverse effects / interactions · 副作用

Cytokine-release syndrome: fever, hypotension, pulmonary edema.

Distinguish · 易混點

Initial TCR cross-linking can activate cells before depletion / inactivation.

Costimulation blockers

Abatacept

→ CTLA-4–Ig binds CD80/86 → CD28 stimulation ↓

Main uses · 用途

RA (lecture focus).

Adverse effects / interactions · 副作用

Infections, infusion / injection reactions.

Distinguish · 易混點

Immunosuppression; opposite net direction to anti-CTLA-4 ipilimumab.

Adhesion blockers

Natalizumab; efalizumab (historical)

→ α4 integrin / CD11a blockade

Main uses · 用途

Natalizumab: selected relapsing MS uses. Efalizumab: historical psoriasis agent.

Adverse effects / interactions · 副作用

PML risk / impaired immune surveillance; infections.

Distinguish · 易混點

Do not present efalizumab as current routine therapy.

Terminal complement blockers

Eculizumab

→ Prevent C5 cleavage → C5a / C5b-9 ↓

Main uses · 用途

PNH (lecture focus; other indications not expanded here).

Adverse effects / interactions · 副作用

Severe meningococcal infection risk.

Distinguish · 易混點

Vaccination / prophylaxis plans matter; upstream C3 functions are not all abolished.

Checkpoint inhibitors

Ipilimumab; nivolumab / pembrolizumab; atezolizumab / avelumab / durvalumab

→ Release CTLA-4 or PD-1 / PD-L1 inhibition

Main uses · 用途

Selected cancers including melanoma, NSCLC, RCC; indications / biomarkers differ by drug.

Adverse effects / interactions · 副作用

Immune-related adverse events: colitis, pneumonitis, hepatitis, endocrinopathies, skin effects.

Distinguish · 易混點

Blocking inhibition increases T-cell activity. These are not interchangeable with abatacept.

IL-2 stimulation

Aldesleukin

→ IL-2 signaling ↑

Main uses · 用途

Selected metastatic RCC / melanoma contexts (lecture).

Adverse effects / interactions · 副作用

Capillary / vascular leak, hypotension, organ dysfunction.

Distinguish · 易混點

Immune stimulation ≠ prevention of graft rejection.

Marrow stimulation

G-CSF; GM-CSF

→ Myeloid cell production ↑

Main uses · 用途

Marrow recovery after myelosuppressive chemotherapy / transplantation.

Adverse effects / interactions · 副作用

Bone pain; agent-specific systemic effects.

Distinguish · 易混點

G-CSF predominantly neutrophils; GM-CSF broader myeloid effects.

Interferons

IFN-α; IFN-β; IFN-γ

→ Immune / antiviral signaling

Main uses · 用途

Lecture: α historical cancer / hepatitis uses; β relapsing MS; γ chronic granulomatous disease.

Adverse effects / interactions · 副作用

Flu-like symptoms; cytopenias / liver and neuropsychiatric effects vary by product.

Distinguish · 易混點

Historical hepatitis use is not a claim of modern HCV first-line treatment.

Older cytotoxic immunosuppressants

Azathioprine / 6-MP; methotrexate; cyclophosphamide

→ Antimetabolite or alkylating effects

Main uses · 用途

Transplant / autoimmune / cancer contexts, drug-dependent.

Adverse effects / interactions · 副作用

Marrow suppression, infection; organ toxicities differ by drug.

Distinguish · 易混點

Lecture lists these but does not fully teach their individual mechanisms here; not expanded as complete oncology lessons.
