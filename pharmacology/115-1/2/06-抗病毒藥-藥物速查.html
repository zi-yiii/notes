Antiviral agents · Drug reference

MechanismsBlock 2

Guanosine analogues · HSV / VZV

Acyclovir; valacyclovir; penciclovir; famciclovir

→ Viral kinase activation → active metabolites inhibit viral DNA polymerase

Main uses · 用途

HSV / VZV infection; acyclovir / valacyclovir are the lecture focus.

Adverse effects / interactions · 副作用

Acyclovir: crystalline nephropathy, neurotoxicity; renal adjustment matters.

Distinguish · 易混點

Valacyclovir is the better-absorbed oral prodrug of acyclovir. Famciclovir → penciclovir; do not assume identical chain-termination chemistry.

Guanosine analogues · CMV

Ganciclovir; valganciclovir

→ CMV UL97 activation → active triphosphate

Main uses · 用途

CMV infection.

Adverse effects / interactions · 副作用

Myelosuppression (neutropenia / thrombocytopenia); neurotoxicity; renal accumulation.

Distinguish · 易混點

Valganciclovir is oral prodrug. CMV UL97 is not HSV thymidine kinase.

Nucleotide analogues

Cidofovir

→ Host kinase activation; no viral kinase requirement

Main uses · 用途

CMV retinitis in the lecture; selected resistant herpesvirus infections.

Adverse effects / interactions · 副作用

Dose-limiting nephrotoxicity; uveitis.

Distinguish · 易混點

IV; probenecid and hydration reduce renal toxicity. Does not bypass polymerase resistance automatically.

Pyrophosphate analogues

Foscarnet

→ Direct inhibition of viral DNA polymerase; no phosphorylation

Main uses · 用途

Resistant CMV and acyclovir-resistant HSV / VZV.

Adverse effects / interactions · 副作用

Nephrotoxicity; electrolyte abnormalities; neurologic toxicity / seizures.

Distinguish · 易混點

No viral kinase and no host activation required.

Local entry blockers

Docosanol

→ Inhibits entry / fusion

Main uses · 用途

Topical herpes labialis.

Adverse effects / interactions · 副作用

Local irritation.

Distinguish · 易混點

Entry blocker, not viral DNA polymerase inhibitor.

Other local / historical herpes agents

Idoxuridine; trifluridine; fomivirsen

→ Nucleoside effects (first two); antisense RNA targeting (fomivirsen)

Main uses · 用途

Local ocular herpes agents; fomivirsen is historical CMV antisense therapy.

Adverse effects / interactions · 副作用

Local ocular toxicity / inflammation; limited host selectivity for older nucleoside agents.

Distinguish · 易混點

Fomivirsen is no longer marketed per lecture; do not present as routine option.

NRTIs · backbone

Lamivudine; emtricitabine; tenofovir

→ Activated analogues inhibit reverse transcription

Main uses · 用途

HIV combination therapy; also HBV activity (drug-specific use).

Adverse effects / interactions · 副作用

Tenofovir: renal / bone toxicity is formulation-dependent; mitochondrial toxicity is a class memory point, especially older agents.

Distinguish · 易混點

Tenofovir is nucleotide analogue. HIV suppression does not eradicate latent provirus. Do not abruptly stop HBV-active therapy without a plan.

NRTIs · abacavir

Abacavir

→ Activated guanosine analogue → RT inhibition

Main uses · 用途

HIV combination therapy.

Adverse effects / interactions · 副作用

Potentially severe hypersensitivity.

Distinguish · 易混點

HLA-B*57:01 screening; never rechallenge after suspected hypersensitivity.

Older NRTIs

Zidovudine; stavudine; didanosine; zalcitabine

→ RT inhibition; mitochondrial DNA polymerase-γ effects contribute toxicity

Main uses · 用途

Lecture / historical drug classification.

Adverse effects / interactions · 副作用

Zidovudine: anemia / marrow suppression; older agents: neuropathy, pancreatitis, lactic acidosis (drug-specific).

Distinguish · 易混點

Do not treat all older agents as current preferred regimens.

NNRTIs

Doravirine; rilpivirine

→ Allosteric HIV-1 reverse transcriptase inhibition

Main uses · 用途

HIV-1 combination therapy.

Adverse effects / interactions · 副作用

Rash / hepatic effects and interactions differ by agent; rilpivirine has acid-suppressant interactions.

Distinguish · 易混點

No phosphorylation; HIV-1, not HIV-2. Not interchangeable with an NRTI.

HIV protease inhibitors

Darunavir; ritonavir

→ Viral polyprotein cleavage / maturation blocked

Main uses · 用途

HIV combination therapy; ritonavir often used as booster.

Adverse effects / interactions · 副作用

GI effects, metabolic abnormalities, hepatic effects, CYP interactions.

Distinguish · 易混點

Immature particles ≠ mature infectious virions. Cobicistat is a booster, not an HIV protease inhibitor.

Pharmacokinetic boosters

Low-dose ritonavir; cobicistat

→ Host CYP3A inhibition → companion exposure ↑

Main uses · 用途

Boost selected HIV regimens; ritonavir boosts nirmatrelvir in Paxlovid.

Adverse effects / interactions · 副作用

Major drug interactions. Ritonavir can cause hepatotoxicity.

Distinguish · 易混點

Boosting is a separate host-metabolism mechanism; ritonavir does not supply the SARS-CoV-2 Mpro inhibition.

CCR5 antagonists

Maraviroc

→ Host CCR5 blockade

Main uses · 用途

CCR5-tropic HIV-1.

Adverse effects / interactions · 副作用

Hepatic injury / hypersensitivity; postural hypotension; CYP interactions.

Distinguish · 易混點

Tropism testing is required; not effective for CXCR4-tropic virus.

Fusion inhibitors

Enfuvirtide

→ Viral gp41 blockade

Main uses · 用途

Selected HIV-1 combination regimens.

Adverse effects / interactions · 副作用

Injection-site reactions.

Distinguish · 易混點

Peptide; subcutaneous administration. Compare host CCR5 vs viral gp41.

INSTIs

Raltegravir

→ Integrase strand transfer inhibition

Main uses · 用途

HIV-1 / HIV-2 combination therapy.

Adverse effects / interactions · 副作用

Rare CK elevation, myopathy / rhabdomyolysis.

Distinguish · 易混點

UGT1A1 metabolism; rifampin lowers exposure. Polyvalent cations can reduce absorption; interactions are not zero.

M2 blockers · historical

Amantadine; rimantadine

→ Influenza A uncoating inhibited

Main uses · 用途

Lecture mechanism; not currently recommended for routine seasonal influenza because resistance is widespread.

Adverse effects / interactions · 副作用

GI / CNS effects; delirium, seizures especially with accumulation; amantadine is renally eliminated.

Distinguish · 易混點

Influenza A only; no influenza B activity. M2 uncoating is distinct from entry / attachment.

Neuraminidase inhibitors · oral

Oseltamivir

→ Virion release inhibited

Main uses · 用途

Influenza A / B treatment and selected prophylaxis contexts.

Adverse effects / interactions · 副作用

Nausea / vomiting; headache; renal adjustment.

Distinguish · 易混點

Oral prodrug → active carboxylate. Does not inhibit influenza RNA synthesis or SARS-CoV-2 polymerase.

Neuraminidase inhibitors · inhaled / IV

Zanamivir; peramivir

→ Virion release inhibited

Main uses · 用途

Influenza A / B.

Adverse effects / interactions · 副作用

Zanamivir: bronchospasm risk; peramivir: diarrhea, renal adjustment.

Distinguish · 易混點

Zanamivir inhaled; peramivir IV. Route is a major distinguishing point.

Cap-dependent endonuclease inhibitors

Baloxavir marboxil

→ Cap-snatching blocked → viral transcription ↓

Main uses · 用途

Influenza A / B treatment; long half-life supports a single dose in applicable settings.

Adverse effects / interactions · 副作用

Polyvalent cations reduce exposure; avoid taking with calcium / iron / magnesium products and dairy at dosing.

Distinguish · 易混點

Prodrug → baloxavir acid; not neuraminidase inhibition.

SARS-CoV-2 polymerase analogues

Remdesivir

→ Active triphosphate interferes with RdRp-mediated RNA synthesis

Main uses · 用途

COVID-19 in eligible patients; IV.

Adverse effects / interactions · 副作用

Transaminase elevations; infusion / hypersensitivity reactions.

Distinguish · 易混點

Do not memorize nucleoside analogues as universally liver-safe.

Mutagenic ribonucleoside analogues

Molnupiravir

→ N-hydroxycytidine incorporation → RNA errors ↑

Main uses · 用途

COVID-19 in selected eligible adults when appropriate alternatives are unsuitable; local criteria apply.

Adverse effects / interactions · 副作用

Embryofetal / reproductive concerns; GI effects.

Distinguish · 易混點

Not simple chain termination. Avoid pregnancy; not for pediatric use.

SARS-CoV-2 protease inhibitors

Nirmatrelvir / ritonavir; ensitrelvir

→ Viral Mpro cleavage blocked

Main uses · 用途

COVID-19; lecture lists oral options; authorization and eligibility are jurisdiction-specific.

Adverse effects / interactions · 副作用

Paxlovid: dysgeusia / diarrhea; major ritonavir-related interactions. Ensitrelvir also has important interactions.

Distinguish · 易混點

Ritonavir is the booster in Paxlovid. HIV protease and SARS-CoV-2 Mpro are different viral enzymes.
